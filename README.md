# Digital Health Assistant Chatbot 🏥

An AI-powered healthcare chatbot platform that provides general health advice, symptom analysis, and possible condition suggestions.

## Features 🌟

- Natural language chat interface for health queries
- Symptom analysis and condition suggestions
- General health recommendations
- Chat history and health reports
- Voice input support
- Responsive design for all devices
- PDF report generation
- Emergency alerts for severe symptoms
- Multi-language support (coming soon)

## Technology Stack 💻

### Backend
- Flask (Python web framework)
- Transformers (HuggingFace)
- GPT-4 API
- SQLite/PostgreSQL
- scikit-learn

### Frontend
- HTML5, CSS3, JavaScript
- TailwindCSS
- Responsive Design
- Speech Recognition API

### AI/ML
- BioBERT for symptom extraction
- Custom diagnosis engine
- GPT-4 for natural conversations

## Installation 🚀

1. Clone the repository:
```bash
git clone https://github.com/akashvim3/Health-Diagnos-Webapp.git
cd Health-Diagnos-Webapp
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Create .env file:
```
SECRET_KEY=your-secret-key
OPENAI_API_KEY=your-openai-api-key
```

4. Run the application:
```bash
python app.py
```

## Usage 📱

1. Open http://localhost:5000 in your browser
2. Start chatting with the AI health assistant
3. View your health dashboard
4. Generate and download health reports

## Security & Privacy 🔒

- No personal health information is stored
- All data is anonymized
- HTTPS encryption
- Session-based chat history
